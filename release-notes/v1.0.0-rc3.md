# Release Notes: aws-object-search v1.0.0-rc3

## Overview
This release candidate adds user documentation for non-technical users, fixes CRAM file filtering, and improves developer tooling with formal release procedures.

## What's New

### User Documentation (#33)
Comprehensive documentation for non-technical intranet users.

- **Prerequisites and vocabulary**: Basic and advanced terminology explained
- **Command overviews**: search-aws and search.py with examples
- **File type filtering**: Usage of -r, -p, -v, -g flags
- **Getting help**: --help option documentation

### Reproducible Builds (#36)
- Added `uv.lock` for consistent dependency resolution
- Reorganized vocabulary into basic and advanced sections

## Bug Fixes

### CRAM Filter Fix (#37)
Fixed `--cram` filter to match generic `.cram` files in addition to `.hgv.cram` files.

Previously, searching with `--cram` would miss files like `sample.cram`. Now both generic CRAM and HGV CRAM files are included.

Fixes #34.
